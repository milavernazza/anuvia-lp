Methodology

From hypothesis to executable decision.

01

Weeks 1-2

Workload & Data Gravity Map

Workloads inventoried. Data sources catalogued (origin, volume, growth rate, sensitivity). Data gravity mapped — where the data is born, where it lives, where it goes. The single most decisive factor for cross-cloud calls.

Deliverable: workload inventory + data gravity diagram

02

Weeks 3-4

Cross-Cloud TCO Model

TCO modeled across scenarios: stay on current cloud (optimized), partial GCP adoption (BigQuery or Vertex specific), full migration, multi-cloud. Egress costs explicit. Reserved Capacity / Committed Use Discounts modeled.

Deliverable: 3-year TCO matrix across scenarios

03

Weeks 5-6

Vendor Lock-In & Operational Overhead

Each scenario assessed for vendor lock-in (proprietary service dependency, talent market, exit cost). Operational overhead of multi-cloud quantified (tooling, skills, incident response, contract management).

Deliverable: lock-in scoring + operational overhead estimate

04

Weeks 7-8

Recommendation & Migration Sketch

Final recommendation with rationale. If GCP adoption recommended, migration sketch (wave plan, pattern selection, account/project structure, network connectivity, identity federation). Executive presentation for board / leadership.

Deliverable: recommendation + migration sketch + exec pack

Metodologia

Da hipótese à decisão executável.

01

Semanas 1-2

Workload & Data Gravity Map

Workloads inventariados. Data sources catalogadas (origem, volume, taxa de crescimento, sensitivity). Data gravity mapeada — onde o dado nasce, onde mora, pra onde vai. Fator único mais decisivo pra decisões cross-cloud.

Entregável: inventário de workloads + diagrama de data gravity

02

Semanas 3-4

Cross-Cloud TCO Model

TCO modelado em cenários: ficar no cloud atual (otimizado), adoção parcial de GCP (BigQuery ou Vertex específico), migração completa, multi-cloud. Egress costs explícitos. Reserved Capacity / Committed Use Discounts modelados.

Entregável: matrix TCO de 3 anos entre cenários

03

Semanas 5-6

Vendor Lock-In & Operational Overhead

Cada cenário avaliado por vendor lock-in (dependência de serviço proprietário, mercado de talento, custo de saída). Overhead operacional de multi-cloud quantificado (tooling, skills, incident response, gestão de contrato).

Entregável: scoring de lock-in + estimativa de overhead operacional

04

Semanas 7-8

Recomendação & Migration Sketch

Recomendação final com racional. Se adoção de GCP recomendada, migration sketch (wave plan, pattern selection, estrutura de account/project, network connectivity, identity federation). Apresentação executiva pra board / liderança.

Entregável: recomendação + migration sketch + exec pack
