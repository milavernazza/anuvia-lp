Methodology

From discovery to migration plan.

01

Weeks 1-2

Discovery & Inventory

AWS Migration Hub + Application Discovery Service deployed to inventory workloads automatically. Manual interviews with workload owners to capture context the tools miss. Network topology, data flows, compliance constraints documented.

Deliverable: workload inventory + dependency map + topology

02

Weeks 3-4

TCO Model

TCO modeled against your existing data center costs (energy, cooling, hardware, ops staff) or current cloud provider invoices including egress. Reserved Instance / Savings Plan commit scenarios modeled. Migration cost vs. ongoing run cost decomposed.

Deliverable: 3-year TCO model with confidence intervals

03

Weeks 5-7

Wave Plan & Pattern Selection

Workloads grouped into waves by dependency, complexity and business risk. Pattern selection per workload (rehost, replatform, refactor, retire). Strangler vs. big-bang call made explicit. Cutover windows mapped to org calendar.

Deliverable: wave plan + pattern catalog + cutover schedule

04

Weeks 8-10

Risk Register & Executive Pack

Risk register with mitigations per workload. Rollback criteria documented. Executive presentation with go/no-go decision support. Optional handover to Anuvia execution squad or your internal team.

Deliverable: risk register + exec pack + handover docs

Metodologia

Do discovery ao plano de migração.

Wave Plan & Pattern Selection
